# Cultural Festival Management System

当システムは、名古屋工学院専門学校で行われる文化祭に於いて、使用者を一意に識別し得点管理、データ収集を簡略化するためのシステムです。

## 機能

### ユーザ登録機能

#### 運営側

運営するゲーム名、ゲーム担当者名、パスワードを登録することで、ゲーム担当者としてログインできるようになる。

#### ユーザ側

##### サイトへのアクセスができるユーザ

* サイトにアクセスした時点でユーザをcookieにより識別する。  
**この時点でユーザID(integer)が付与され**IDとQRコードが表示される。

* 料金を支払ったらユーザの状態を「支払い済み」に変更する。

##### サイトへのアクセスができないユーザ

* ユーザの代わりにIDを発行する。
その際にIDを紙に書いて渡す。

### 得点管理機能

* ユーザの得点を登録、更新、削除する機能。

各ゲーム担当者はスマホまたは紙に書かれたID,QRコードを読み取り、得点を登録する。
